# Cowworker

**Тема проекта:** Платформа для поиска и бронирования coworking-пространств  
**Используемый фреймворк:** Bulma  

**Ссылка на рабочий сайт:** https://b4bqkpq4wp-art.github.io/cowworker-project/

В проекте сделан одностраничный лендинг. Есть фиксированная шапка, блок поиска с фильтрами, карточки коворкингов и подвал с контактами. Стили подключены через CDN Bulma, лишнего кода и библиотек нет.
